# Repository Intelligence Platform

An AI-powered Repository Intelligence Platform that analyzes source code using AST parsing, metadata extraction, dependency analysis, semantic search, and Retrieval-Augmented Generation (RAG) to help developers understand large codebases.

## Tech Stack

- Node.js
- Express.js
- PostgreSQL
- Prisma
- Zod
- Gemini API
- Tree-sitter
- pgvector
